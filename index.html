Projetos Principais

API de OCR + LLM para Análise Inteligente de Currículos

API RESTful pronta para produção, desenvolvida com FastAPI, PaddleOCR e Hugging Face Transformers, voltada à automação da extração e interpretação de currículos. Realiza OCR em arquivos PDF/imagem, aplica LLMs para sumarização ou Q&A, e registra as requisições em um banco MongoDB para auditoria.

A arquitetura é modular, orientada a ambientes, com logging estruturado e totalmente containerizada com Docker, oferecendo suporte a deploy em um único comando via Docker Compose.

Stack Tecnológica:

FastAPI Python PaddleOCR Hugging Face Transformers PyMongo MongoDB Docker

Portfólio Interativo com IA Generativa

Plataforma full-stack que utiliza RAG (Retrieval-Augmented Generation) para comparar meu currículo com requisitos de vagas em linguagem natural. O sistema combina embeddings semânticos, LangChain e LLMs (via Gemini) para avaliar aderência profissional com justificativas contextualizadas, simulando entrevistas técnicas.

O backend é construído com FastAPI, indexa documentos locais, realiza buscas vetoriais com Hugging Face e responde por meio de LLMs. Totalmente containerizado e hospedado gratuitamente no Hugging Face Spaces, com frontend leve em HTML/JS hospedado via GitHub Pages.

Stack Tecnológica:

FastAPI LangChain Python Gemini 1.5 Pro Hugging Face Embeddings RAG Docker GitHub Pages TailwindCSS

Sales Insights API – RAG-Driven Natural Language Interface

API RESTful para análise de vendas com arquitetura RAG baseada no Gemini, LangChain e PostgreSQL. Permite consultas complexas em linguagem natural — como “Qual foi o produto mais vendido no último mês?” — traduzidas automaticamente para SQL e respondidas com clareza.

Todo o pipeline é orquestrado via LangChain, com execução SQL via SQLAlchemy e resposta final gerada em linguagem natural. Totalmente containerizada e pronta para produção.

Stack Tecnológica:

FastAPI Python LangChain Gemini API PostgreSQL SQLAlchemy Docker
